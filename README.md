# Frameclash

## What is Frameclash:

Frameclash is a bullet-hell topdown arena shooter, in which you have to shoot as many tanks captured by the evil laptops as you can, upgrade your tank in the loadout and survive as many waves as possible

## How was this made/how can i mod this:

Frameclash was made in Godot 4.5.1.stable, and uses the Compatibility render. It should also be edited using that.
